# Plan 05-04 — Contract fixes, then build and deploy `aiostreams-jf:2.34.0-jf3`

## Part A — code fixes (local repo)

### A1. Encode Stremio extras — `packages/core/src/jellyfin/service.ts:114-122`
`extrasBase.push(\`search=${opts.search}\`)` and `genre=${opts.genre}` → wrap the values in `encodeURIComponent(...)`. A search term with `&` or `=` currently corrupts the extras string and can inject `skip=`.

### A1b. Engine init must not stay poisoned — `service.ts` `getEngine()` (~line 57-70)
Since 05-02 the service lives for the 5-minute user-cache TTL, so a rejected `initialise()` would leave `initPromise` rejected for every request in that window. Add `.catch((e) => { this.initPromise = null; throw e; })` to the init chain so the next call retries.

### A2. Remove double decode — `library.ts`
`/Genres/:name` (~line 876) and `/Persons/:name` (~line 985) call `decodeURIComponent(param(req,'name'))` on already-decoded params; a literal `%` throws `URIError`. Use `param(req, 'name')` directly.

### A3. Literal `/Items/*` routes before `/Items/:itemId` — `library.ts`
Move the `'/Items/Filters'`, `'/Items/Filters2'`, `'/Items/Counts'` handlers (and the `/Users/:userId/Items/Latest`, `/Items/Latest`, `/Users/:userId/Items/Resume`, `/UserItems/Resume` handlers if they are defined after it) so they are registered **before** the `['/Users/:userId/Items/:itemId', '/Items/:itemId']` route (~line 672). Then delete `RESERVED_ITEM_IDS` and its `next('route')` pre-handler. Express matches in registration order, so this removes the fragile guard. Check `system.ts` too: its stubs for `/Items/Intros`, `/Users/:userId/Items/Intros` are on `systemRouter`, which is mounted before `libraryRouter` in `index.ts`, so they already win.

### A4. Filter before slicing + honest totals — `library.ts` view branch (~329-348)
- Request `limit` from the catalog, apply `filterByType`/`applyUserFilters` to the page, and if the filters removed items and `page.hasMore`, fetch one more page (loop at most 3 times) to top up to `limit`. Keep the `startIndex` arithmetic consistent by tracking the raw offset consumed.
- `TotalRecordCount`: when `page.hasMore`, report `startIndex + filtered.length + limit` (unchanged); when not, `startIndex + filtered.length`. Remove the `offset += 1` fudge in the recursive crawl (~line 391) — it desynchronises the next page.

### A5. `qb()` accepts `1`/`0` — `context.ts:479-483`
Return `true` for `'true' | '1'`, `false` for `'false' | '0'`, else `undefined`. Kodi sends `Recursive=1`.

### A6. Build + test + commit
`pnpm build`; `pnpm --filter ./packages/core test`. Commit `fix(jellyfin): encode extras, drop double decode, route order, filter-before-slice, qb 1/0`; push `release`.
