# Plan 07-01 — Person filmography, Similar, hide empty/search-only libraries, sort once, cheaper builds

All findings verified live on 2026-09-09 against `ghcr.io/tweakapps/aiostreams-jf:release` (`44c7b928`); see `/Users/magededward/claude-cc/aiostreams-jf-review-2026-09-09.md` sections 1 and 2.

## Steps

### 1. Person filmography (D1) — `library.ts` ~line 311
Infuse sends `GET /Users/{uid}/Items?PersonIds=<personId>&Recursive=true…` (no ParentId). The branch only reads the name when `parent.k === 'person'`, so `name` is null and it returns nothing.
- When `personIds.length`, decode `personIds[0]` with `decodeJellyfinId`; if `k === 'person'` use its `n`.
- Search with `ctx.service.search(name, stremioTypesFor(types), limit)`; the AioMetadata profile has "People Search" catalogs (`people_search.people_search_movie/series`) which take a person name, so this already returns filmography. Keep dedupe by `type|id`.
- Return `list(filterByType(items, types), items.length, 0)`.

### 2. Similar (D4) — `library.ts` ~line 826-860
- Compare genres case-insensitively and trimmed: `opts.some(o => o.toLowerCase() === genre.toLowerCase())`. Try every genre of the item, not only the first, until one matches a catalog.
- If no catalog matches any genre, fall back to `ctx.service.search(<item name first word or full name>, [d.t], limit + 1)` and filter out the item itself. Return up to `limit`.
- Wrap everything in the existing `safeCatalogPage` / try-catch so it never 500s.

### 3. Hide search-only and empty libraries (D5) — `items.ts` `viewItems`, `service.ts`
- In `viewItems`, exclude catalogs where `extra` contains an entry `name === 'search'` with `isRequired === true`. (AioMetadata's "Movies Search", "Series Search", "Anime … Search", "People Search" ×2 and "Voice Actor Roles" are all search-required; verify by dumping `catalog.extra` for the c05bd9bc profile in a quick script if unsure.) These catalogs stay available to `search()`.
- Add to `JellyfinService` a tiny per-instance `emptyCatalogs: Map<string, number>` (key `type|id`, value = expiry ms). In `getCatalogPage`, when a fetch with no search/genre and `startIndex === 0` returns zero items, set the key for 10 minutes; when it returns items, delete the key. Expose `isKnownEmpty(catalog)`.
- `viewItems` also drops catalogs where `service.isKnownEmpty(catalog)`. First-ever load still shows them (unknown state) and the home fan-out marks them; the next `UserViews` hides them. Document this in a code comment.
- `findCatalog` must still resolve hidden catalogs (clients may hold old view ids).

### 4. Sort once (R3) — `library.ts` view branch ~line 357-386
Move `applySort` out of the top-up loop: collect `filtered` across pages, then `applySort(req, filtered).slice(0, limit)`.

### 5. Person-image write memo (R5) — `dto.ts` `peopleFrom`
Module-level `const rememberedPeople = new Map<string, number>()` (key `uuid|personId`, value expiry = now + 10 min, cap 20 000 entries, drop oldest on overflow). Only call `rememberImages` when the key is absent or expired. Same guard in `buildPersonItem`.

### 6. Season lookups scoped (R6) — `items.ts` `seasonsForSeries`, `episodesForSeries`
`seasonsForSeries` currently encodes every episode id for every season to fetch playstates. Keep that for the seasons list (it needs per-season played counts) but add a `seasons?: number[]` option and use it from `/Shows/:id/Episodes?SeasonId=` and `itemFromDescriptor('season')` so a single-season request only encodes that season's episode ids. Verify with a quick count log in a test.

### 7. Tests — `dto.test.ts`
- `peopleFrom` called twice for the same meta triggers `rememberImages` once per person (spy on the images module or on the Cache set).
- Add a `library`-level test only if the repo already has server-side tests; otherwise skip (the server package has no test harness — check `packages/server/package.json`).

`pnpm build` zero errors; `pnpm --filter ./packages/core test` green (57 + new). Commit `fix(jellyfin): person filmography, similar fallback, hide search-only/empty libraries, sort once, memoised person images, scoped season lookups`; push `origin release`. No deploy (07-02 deploys).
