# Plan 07-02 — Image redirects with TMDB sizing, PlaybackInfo cap, test setup, README security notes; deploy via GHCR

## Steps

### 1. Public artwork by redirect (D2) — `playback.ts` `imageUrlFor` + image route
Measured: backdrop relay = 1.5 s and 1.7 MB per request; every artwork URL is treated as `public: false` and proxied.
- Add `const PUBLIC_IMAGE_HOSTS = ['image.tmdb.org', 'artworks.thetvdb.com', 'images.metahub.space', 'm.media-amazon.com', 'assets.fanart.tv']`. In `imageUrlFor`, when the resolved URL's hostname ends with one of these, return `{ url, public: true }`.
- Add `sizeImageUrl(url, want, req)`: read `maxWidth` / `maxHeight` / `fillWidth` / `fillHeight` / `width` (query, case-insensitive via `qi`). For `image.tmdb.org/t/p/<size>/…` rewrite `<size>` to the smallest TMDB bucket ≥ the requested width: posters `w185, w342, w500, w780, original`; backdrops `w300, w780, w1280, original`; profile (person) `w185, h632, original` — TMDB only accepts these exact names. If no size requested, use `w500` for Primary, `w1280` for Backdrop, `w185` for person Primary. Leave non-TMDB hosts untouched.
- In the GET image route: when `result.public`, `res.redirect(302, sized)` with `Cache-Control: public, max-age=86400`; only relay non-public URLs (addon-private or unknown hosts). HEAD mirrors this (302 for public, 200 for relayable).
- Keep the existing warn log + 404 fallback for relay failures.

### 2. PlaybackInfo cap (D3) — `playback.ts` PlaybackInfo, `api.ts`
- New config `jellyfinMaxPlaybackSources` (env `JELLYFIN_MAX_PLAYBACK_SOURCES`, default 20). Clients matching `jellyfinAttachSourcesClients` (SenPlayer) get the existing 50.
- Beyond the first 5 sources, omit `MediaStreams` (set `[]`) to cut the payload; Infuse reads streams from the selected source at play time via the stream itself. Verify `resolveStreamTarget` does not depend on `MediaStreams` for non-default sources (read it before editing).
- Note in the config description that Infuse shows a picker only briefly and picks the first source by default.

### 3. Test setup (R7) — `packages/core`

Remove the manual first-line barrel import from `dto.test.ts` once the setup works.

### 4. README security notes (R9)
Under the Jellyfin section add "Security notes": (a) API tokens embed the encrypted profile password and cannot be revoked; treat them like the password; (b) alias logins accept any password by design (aliases are share links) — do not create an alias for a profile you expose through the Jellyfin layer unless you intend it to be open; (c) Jellyfin rate limit is `JELLYFIN_WINDOW/MAX` (default 5 s / 2000). Also one line: "Do not enable AioMetadata's subtitles resource for profiles used via the Jellyfin layer (its Trakt/Simkl check-in fires from subtitle requests)."
