# Plan 06-02 — Map the metadata AioMetadata already sends; person pages; deploy jf7

## Facts (live meta from AioMetadata, 2026-09-09; `MetaSchema` is zod passthrough so all of this reaches `ParsedMeta`)
- `app_extras.certification`: `"R"`, `"TV-MA"` (movie and series). `app_extras.certificationLocal` also present. The layer currently returns `OfficialRating: null`.
- `_tmdbId`, `_tvdbId`, `_imdbId`, `imdb_id` at top level. Layer returns `ProviderIds: { Imdb }` only.
- `app_extras.cast`, `app_extras.directors`, `app_extras.writers` are ALL arrays of `{ name, character, photo }` objects (photo may be `null`). The jf3 `peopleFrom` handles `cast` objects but filters `directors`/`writers` with `typeof === 'string'`, so crew is dropped or falls back to name-only `links`.
- `app_extras.seasonPosters` (series): map of season → poster URL (inspect the exact shape at runtime: log it once in a test run, or read `/tmp/meta.json` on the VPS from the 2026-09-09 probe; handle both `{ "1": url }` and `[{ season, poster }]`).
- `trailers[].source`/`trailerStreams[].ytId` already mapped to `RemoteTrailers` (verified).
- `videos[]` (episodes) have `thumbnail`, `overview`, `released`, `runtime`; no per-episode cast. Episode `People` is currently `null`.
- No studios/networks in the meta — leave `Studios: []`.

## Steps

### 1. `dto.ts` — `buildMetaItem`
- `OfficialRating`: `app_extras.certification` if non-empty string, else `app_extras.certificationLocal`, else undefined.
- `ProviderIds`: add `Tmdb` from `_tmdbId` and `Tvdb` from `_tvdbId` when present (stringified). Keep `Imdb`.
- `peopleFrom`: treat `directors`, `director`, `writers` entries the same way as `cast` (string OR `{name, character, photo}`), Type `Director` / `Writer`, photo remembered + `PrimaryImageTag` set. Dedupe by name is already in place — but a person who is both actor and director should appear twice with different `Type` (Jellyfin allows it); change the dedupe key to `name|type`.
- Bump `JELLYFIN_DTO_VERSION` to 3 (Etag input already includes people and will change anyway; the bump is the documented discipline).

### 2. `dto.ts` — episodes and seasons
- `buildEpisodeItem`: set `People` to the series item's `People` (pass `seriesItem.People` through; it is already built in `items.ts` `episodesForSeries` / `itemFromDescriptor('episode')`). Infuse shows the cast row on episodes too.
- `buildSeasonItem`: if `app_extras.seasonPosters` has an entry for the season number, use it as `images.Primary` (remember it via `rememberImages` under the season id) and set `ImageTags.Primary`; otherwise keep the current series-poster fallback.

### 3. Person pages — `items.ts` + `dto.ts`
- `itemFromDescriptor` case `'person'`: `const photo = (await recallImages(ctx.uuid, encodeJellyfinId(d)))?.images.Primary` and pass it to `buildPersonItem(ctx.build, d.n, photo)` (signature added in 05-03). `recallImages` is exported from `@aiostreams/core` (check `packages/core/src/index.ts`; export it if missing).
- `buildPersonItem`: when a photo is present also set `Etag: imageTag(JSON.stringify([JELLYFIN_DTO_VERSION, id, photo]))`.
- The image cache TTL for remembered person photos is 7 days (`images.ts` `TTL`); that is acceptable.

### 4. Tests — `dto.test.ts`
Add cases (keep the `import '../index.js'` first-line workaround):
- certification → `OfficialRating: 'R'`; `_tmdbId: 123` → `ProviderIds.Tmdb === '123'`.
- `app_extras.directors = [{ name, character, photo }]` → one `Director` with `PrimaryImageTag`.
- Same name in cast and directors → two entries (Actor + Director).

### 5. Build, test, commit
`pnpm build` zero errors; tests green. Commit `feat(jellyfin): certification, tmdb/tvdb ids, crew photos, episode cast, season posters, person photos (dto v3)`; push `origin release`.
